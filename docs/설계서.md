# 설문 집계기 설계서

## 1. 목적
과학관 직원이 엑셀에서 만족도 응답을 복사해 붙여넣으면 문항별 결과 표를 보여준다.

- 쓰는 사람: 과학관 직원
- 응답: 1~5점 척도, 문항 약 10개
- 쓰는 곳: PC와 휴대폰 브라우저
- 원칙: 어떤 데이터도 브라우저 밖으로 나가지 않는다.

## 2. 정해진 사항

### 2.1 입력 (고정)
- 머리글 줄까지 함께 붙여넣는다.
- 첫 열은 응답번호이므로 집계하지 않는다.

### 2.2 결과 표 (고정)
- 문항마다 한 줄씩 **유효 응답 수 · 평균 · 빈 응답 수 · 제외 수**를 보여준다.
- 평균은 소수 셋째 자리에서 반올림한다(소수 둘째 자리까지 표시, 예: 3.00).
- 유효 응답이 0이면 평균 칸에 "-"를 표시한다.
- 점수별 분포(1~5점 각각의 개수)는 보여주지 않는다.

### 2.3 결과 활용
- 결과는 화면에만 보여준다. 복사 버튼이나 파일 저장 기능은 두지 않는다.

### 2.4 배포
- 웹 주소로 연다(GitHub Pages 같은 정적 호스팅).
- 주소를 열 때 페이지 파일만 받아 온다. 붙여넣은 데이터는 어디로도 보내지 않는다.

### 2.5 칸 수가 머리글과 다른 줄
- 칸이 모자라면 모자란 칸을 빈 응답으로 센다.
- 칸이 남으면 남는 칸은 무시한다.
- 이런 줄이 있었으면 몇 번째 줄인지 안내 문구로 알려준다.

## 3. 데이터 처리 규칙
① **유효:** 앞뒤 공백을 지운 값이 1, 2, 3, 4, 5 중 한 글자일 때만 유효로 보고 평균에 넣는다.
② **빈 응답:** 비어 있거나 공백만 있는 칸은 빈 응답으로 따로 센다.
③ **제외:** 그 밖의 값(범위 밖 숫자, 4.0, 글자)은 제외로 따로 센다.

## 4. 시험 사례
한 문항에 대한 응답들을 넣었을 때의 기대 결과:

| 사례 | 응답 | 유효 | 빈 응답 | 제외 | 평균 |
|---|---|---|---|---|---|
| 사례1 | 1, 2, 3, 4, 5 | 5 | 0 | 0 | 3.00 |
| 사례2 | 5, (빈칸), 3 | 2 | 1 | 0 | 4.00 |
| 사례3 | 4, 6, 0, 4점, 3 | 2 | 0 | 3 | 3.50 |
| 사례4 | (빈칸), (빈칸), (빈칸) | 0 | 3 | 0 | "-" |

## 5. 제가 정한 가정 (확인 필요)
요청에 정해져 있지 않아 아래처럼 가정했습니다. 다르면 알려 주세요.
- 가. 엑셀에서 복사한 값은 칸이 탭으로 나뉜다고 보고 그대로 읽는다.
- 나. 완전히 빈 줄(예: 붙여넣은 끝의 빈 줄)은 응답으로 세지 않고 무시한다.
- 다. 문항 수는 10개로 고정하지 않는다. 머리글에 있는 만큼 집계한다.
- 라. 결과 표의 문항 이름은 머리글에 적힌 이름을 그대로 쓴다.
- 마. 화면 글자는 모두 한국어로 쓴다.
- 바. 저장소가 비공개이면 요금제에 따라 GitHub Pages를 못 쓸 수 있다. 그때는 배포 방법을 다시 정한다.

## 6. 성공 확인 기준

### 6.1 파일과 의존성
- [ ] 결과물은 HTML 파일 하나이고, 그 파일만 열어도 모든 기능이 동작한다.
- [ ] 파일 안에 외부 라이브러리, 외부 글꼴, 분석 도구를 불러오는 부분이 없다.

### 6.2 데이터가 밖으로 나가지 않음
- [ ] 브라우저 개발자 도구의 네트워크 탭을 열어 두고 페이지를 연 뒤 데이터를 붙여넣고 집계해도, 페이지를 처음 받아 올 때 말고는 요청이 하나도 생기지 않는다.
- [ ] 집계한 뒤 개발자 도구의 저장소 항목(로컬 저장소, 세션 저장소, 쿠키, IndexedDB)이 모두 비어 있다.
- [ ] 페이지를 새로 고치면 붙여넣은 데이터와 결과가 모두 사라진다.

### 6.3 계산
- [ ] 계산 로직이 화면 코드와 떨어져 있어, 화면 없이 따로 시험을 돌릴 수 있다.
- [ ] 자동 시험에 4장의 사례1~4가 모두 들어 있고, 모두 통과한다.
- [ ] 자동 시험에 2.5의 처리(모자란 칸은 빈 응답, 남는 칸은 무시)를 확인하는 사례가 있고, 통과한다.
- [ ] 문항마다 유효 + 빈 응답 + 제외가 전체 응답 수와 같다.
- [ ] 첫 열(응답번호)은 결과 표에 나오지 않는다.

### 6.4 화면 (PC)
- [ ] 엑셀에서 머리글을 포함해 범위를 복사해 붙여넣으면, 문항마다 한 줄씩 유효 응답 수·평균·빈 응답 수·제외 수가 나온다.
- [ ] 평균은 소수 둘째 자리까지 나오고, 유효 응답이 0인 문항은 평균 칸이 "-"이다.
- [ ] 칸 수가 머리글과 다른 줄이 있으면 몇 번째 줄인지 안내 문구가 나온다.

### 6.5 화면 (휴대폰)
- [ ] 폭 360px 화면에서 페이지 전체가 가로로 밀리지 않는다.
- [ ] 휴대폰에서 웹 주소로 열어 붙여넣기 칸에 데이터를 붙여넣으면 PC와 같은 결과 표가 나온다.
- [ ] 결과 표의 글자와 숫자를 확대하지 않고도 읽을 수 있다.
